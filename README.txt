CLASS DAVENING PLAYER — WITH AUDIO INCLUDED

1. Extract/unzip the whole folder.
2. Keep the "audio" folder next to index.html.
3. Open index.html in Chrome or Edge.

The recordings from the uploaded ZIP have been converted to compact MP3 files and built into the app.
The Tanya recording from the uploaded ZIP was intentionally not included in the davening sequence.

Features:
- Hebrew tefillah names
- Real uploaded recordings already included
- Play/Pause, Restart, 10 seconds back/forward
- Previous/Next tefillah
- Automatic continuation to the next recording
- Playback speed control
- Full-screen Student View
- No siddur text shown

Keyboard:
Space = Play/Pause
Left Arrow = Previous tefillah
Right Arrow = Next tefillah

Second audio set added: ויציב, מי כמוך, שמונה עשרה — חורף, קוה אל ה׳, עלינו לשבח, אל תירא, קאפיטל של הרבי, י״ב הפסוקים.
